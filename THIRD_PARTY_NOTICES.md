## License source and retained notices

The Apache 2.0 text is retained from the pinned AndroidX Annotation
1.10.0 artifact (`META-INF/androidx/annotation/annotation/LICENSE.txt`); the
AndroidX Startup 1.2.0 artifact includes the same text. Published Maven POMs
for the locked modules declare Apache 2.0, directly or through their parent POM
(including Guava). The runtime artifacts were also inspected for separate
META-INF license/NOTICE files, including nested classes.jar files in AARs.
No additional runtime NOTICE files were present in the inspected artifacts.
Preserve any such files if future updates introduce them.

The same inventory and full license text are bundled in the APK and can be
read in About → Third-party licenses without a network connection.

## Updating this inventory

After an explicitly approved dependency change, review the resolved runtime
coordinates and each publisher’s license and NOTICE files, update
`third-party/runtime-dependencies.json` and this document, and retain any new
license texts under `LICENSES/`. Run `:app:verifyThirdPartyNotices` and inspect
the final APK’s `assets/legal/` entries. Do not solve a verification failure by
excluding an unreviewed dependency from the inventory.
