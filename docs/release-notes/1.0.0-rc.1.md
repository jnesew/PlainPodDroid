# PlainPodDroid 1.0.0-rc.1

First release candidate for an Android podcast player that keeps your library
on your device and works without Google Play Services.

- Add RSS feeds, Apple Podcasts links or OPML subscriptions.
- Stream episodes or download them, build a queue and use chapters, playback
  speed, sleep timer and configurable skip controls.
- Browse favorites, new episodes, listening history and unfinished listening.
- Enable Offline mode to stop all app network activity while keeping downloaded
  episodes, saved information and cached covers available.
- Use manual/automatic downloads, storage limits and optional cleanup.
- Choose Download before playing to save the full episode before audio starts.
- Schedule refresh and automatic downloads by weekday and local time, with
  optional unmetered/charging constraints and a last-attempt summary. Allow time
  before departure because Android may delay background work.
- Read the MIT application license and third-party licenses offline in About.

If Offline mode was enabled in an earlier test build, it now stops feed,
cover-art, chapter and Apple lookup traffic as well as audio transfers.
Long archives support up to 32 MiB and 10,000 episodes, with additional bounded
text and structure limits.

Requires Android 10 or newer. This is a pre-release for device acceptance,
not a claim that the integrated device test plan is complete.

The signed release packet records the source commit and signing certificate in
`PROVENANCE.json`, with artifact checksums in `SHA256SUMS`.
