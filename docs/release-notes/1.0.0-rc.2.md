# PPodcast 1.0.0-rc.2

Release candidate for device testing, prepared on 2026-11-14.

- Renamed the app to PPodcast. The application ID and update identity remain
  the same, preserving existing subscriptions, downloads and settings.
- Fixed automatic playback of the next queued episode, including Download
  before playing. Offline mode and sleep timers continue to control playback;
  an unavailable next episode stays queued instead of being skipped.
- Podcast audio now pauses when another app takes audio focus. Temporary
  interruptions pause speech instead of lowering its volume and resume when
  focus returns, unless you paused manually. Starting other media leaves the
  podcast paused until you choose Play.
- Simplified Podcasts with one Add button at the top and gave New episodes its
  own navigation icon. Favorite and queue highlights no longer overlap in the
  Episode view.
- Grouped playback speed and sleep timer controls, removed repeated default
  speed explanations, and moved the global default speed to Settings.
- Made queue status quieter: the current episode uses a highlight, with a
  violet accent in dark mode. Up next appears near the end of playback;
  action-required warnings appear immediately. Empty queues stay quiet.
- Debug builds appear as PPodcast Debug and install alongside the release app.

Android version code: 3. Requires Android 10 or newer. This candidate remains
subject to physical-device acceptance, including real media-app interruptions,
calls, background playback and headset behavior. It is not a stable-release or
publication announcement.
